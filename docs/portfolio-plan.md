# Como este projeto vira portfólio

## Nome sugerido

**Analytics Commerce Lab — Implementação de Digital Analytics em E-commerce**

## Descrição curta

Projeto prático de Digital Analytics em um e-commerce fictício, com implementação de mensuração usando Google Analytics 4 e Google Tag Manager, Data Layer, eventos de navegação e e-commerce, funil de conversão, integração com BigQuery, consultas SQL e dashboard no Looker Studio.

## Entregáveis finais

- Site publicado.
- Plano de mensuração.
- Mapa de eventos.
- Implementação do GTM.
- Eventos e conversões no GA4.
- Evidências no DebugView / Tag Assistant.
- Funil de e-commerce.
- Integração com BigQuery.
- Queries SQL documentadas.
- Dashboard no Looker Studio.
- README com arquitetura e screenshots.
